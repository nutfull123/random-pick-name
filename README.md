# สุ่มชื่อ

เว็บสุ่มชื่อ นำเข้ารายชื่อจาก Excel/CSV เลือกคอลัมน์ชื่อ-นามสกุล แล้วสุ่มทีละคน

**ใช้งาน:** https://nutfull123.github.io/random-pick-name/

- นำเข้า .xlsx, .xls, .csv หรือ .zip ที่มีไฟล์เหล่านี้ (ไฟล์อ่านในเบราว์เซอร์ ไม่ถูกส่งไปที่ไหน)
- ตรวจและลบชื่อซ้ำก่อนเริ่มสุ่ม
- สุ่มแบบชื่อวิ่ง หรือแบบวงล้อ
- ตัดชื่อที่สุ่มได้ออก หรือสุ่มซ้ำได้
- ใส่รางวัล/ภารกิจตามลำดับการสุ่ม
- กด Shift เพื่อสุ่ม

ทดสอบ: เปิด `index.html` แล้วรัน `runTests()` ใน console (หรือเปิดด้วย `?test`)
