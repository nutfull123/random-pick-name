# Random Pick Name — Design

Date: 2026-10-23

## Goal

เว็บสุ่มชื่อที่แชร์ลิงก์ได้ นำเข้ารายชื่อจากไฟล์ Excel/CSV หลายคอลัมน์ แล้วใช้เฉพาะคอลัมน์ "ชื่อ-นามสกุล" ที่ผู้ใช้เลือกเอง

### What the user said
- นำเข้าไฟล์ Excel/CSV ที่มีหลายคอลัมน์ ใช้เฉพาะส่วนชื่อ-นามสกุล
- ผู้ใช้เลือกคอลัมน์เองทุกครั้ง (ไม่เดาอัตโนมัติ)
- เลือกได้ทั้งสองแบบ: ตัดชื่อที่สุ่มได้ออก หรือสุ่มซ้ำได้
- เป็นเว็บที่แชร์ลิงก์ได้

### Assumptions
- ใช้ในห้องเรียน/ประชุม อาจฉายโปรเจกเตอร์ → ชื่อต้องตัวใหญ่ อ่านง่าย
- ชื่อภาษาไทยเป็นหลัก
- ไม่มีล็อกอิน ข้อมูลรายชื่อไม่ออกจากเบราว์เซอร์ของผู้ใช้

### Success criteria
1. นำเข้า .xlsx, .xls, .csv (UTF-8, UTF-8 BOM) ที่มีภาษาไทยได้โดยตัวอักษรไม่เพี้ยน
2. ผู้ใช้เห็นตัวอย่างข้อมูล เลือกคอลัมน์ได้ และได้รายชื่อเฉพาะคอลัมน์นั้น (ไม่รวมแถวหัวตารางและช่องว่าง)
3. กดสุ่มแล้วได้ชื่อแบบสุ่มยุติธรรม พร้อมแอนิเมชันวนชื่อ
4. โหมดตัดออก: ไม่มีชื่อซ้ำจนครบทุกคน แล้วแจ้งว่าครบ; รีเซ็ตได้
5. ใช้งานได้บนมือถือและเดสก์ท็อป ทั้งธีมสว่าง/มืด

## Approach

หน้า HTML ไฟล์เดียว อ่านไฟล์ด้วย SheetJS (`xlsx` จาก cdnjs, เวอร์ชันระบุตายตัว) ทำงานฝั่งเบราว์เซอร์ทั้งหมด เผยแพร่เป็น Artifact บน claude.ai (ส่วนตัวก่อน ผู้ใช้กดแชร์เอง)

ทางเลือกที่ไม่เลือก: CSV อย่างเดียวเขียนตัวอ่านเอง (ผู้ใช้ต้องแปลงไฟล์ และภาษาไทยเพี้ยนบ่อย), React/Vite (หนักเกินงาน)

## UI flow (หน้าเดียว 3 ขั้น)

1. **นำเข้า** — โซนลากวาง + ปุ่มเลือกไฟล์ (`accept=".xlsx,.xls,.csv"`). ถ้ามีหลายชีต แสดง `<select>` เลือกชีต
2. **เลือกคอลัมน์** — ตารางตัวอย่าง 5 แถวแรก; แถวแรกเป็นหัวตาราง. ผู้ใช้คลิกหัวคอลัมน์ (เป็นปุ่ม เข้าถึงด้วยคีย์บอร์ดได้) เพื่อเลือก คอลัมน์ที่เลือกไฮไลต์ แสดง "พบ N รายชื่อ" แล้วกด "ใช้รายชื่อนี้"
3. **สุ่ม** — ชื่อตัวใหญ่กลางจอ ปุ่ม "สุ่ม" (คีย์ลัด Shift: กด-ปล่อย Shift เดี่ยวๆ), สวิตช์ "ตัดชื่อที่สุ่มได้ออก" (ค่าเริ่มต้น: เปิด), ปุ่ม "รีเซ็ต", ปุ่ม "เปลี่ยนไฟล์", แผงข้าง: "เหลืออีก N คน" และ "ประวัติที่สุ่มได้" (ล่าสุดอยู่บน)

แอนิเมชัน: วนชื่อแบบสุ่มเร็วแล้วช้าลง ~1.5 วินาที แล้วหยุดที่ผู้ถูกเลือก (ตัดสินผลก่อนเริ่มแอนิเมชัน). ถ้า `prefers-reduced-motion` แสดงผลทันที. ผลลัพธ์อยู่ใน `aria-live="polite"`.

## Units

| Function | Input → Output | Notes |
|---|---|---|
| `parseFile(file)` | `File` → `{ sheets: { [name]: string[][] } }` | SheetJS `read` + `sheet_to_json({header:1, raw:false, defval:""})` |
| `extractNames(rows, col)` | `string[][]`, index → `string[]` | ข้ามแถวแรก (หัวตาราง), `trim`, ยุบช่องว่างซ้ำ, ตัดค่าว่าง |
| `randomIndex(n)` | `number` → `number` | `crypto.getRandomValues` + rejection sampling กัน modulo bias |
| `pick(state)` | `{ pool, removeAfter }` → `{ name, pool }` | โหมดตัดออก: ลบชื่อนั้นออกจาก pool |

State: `allNames`, `pool`, `history`, `removeAfter`. รีเซ็ต = `pool = [...allNames]`, `history = []`. สลับสวิตช์จากตัดออก → สุ่มซ้ำ: pool กลับเป็นทุกคน (ประวัติยังอยู่).

ชื่อซ้ำกันในไฟล์ (คนชื่อเหมือนกัน) ถือเป็นคนละคน — ไม่ dedupe.

## Errors

- ไฟล์อ่านไม่ได้ / นามสกุลไม่รองรับ → "อ่านไฟล์นี้ไม่ได้ กรุณาใช้ .xlsx, .xls หรือ .csv"
- ชีตว่าง → "ชีตนี้ไม่มีข้อมูล"
- คอลัมน์ที่เลือกไม่มีชื่อ → ปุ่ม "ใช้รายชื่อนี้" ปิด + "คอลัมน์นี้ไม่มีรายชื่อ"
- pool หมด → ปุ่มสุ่มปิด + "สุ่มครบทุกคนแล้ว — กดรีเซ็ตเพื่อเริ่มใหม่"

ข้อความแสดงด้วย `textContent` เท่านั้น (ชื่อจากไฟล์ไม่ถูกตีความเป็น HTML).

## Testing

- Self-check ในหน้า (รันเมื่อ URL มี `?test`): `extractNames` (หัวตาราง, ช่องว่าง, trim), `randomIndex` อยู่ในช่วง, `pick` โหมดตัดออกไม่ซ้ำจนครบ
- ทดสอบในเบราว์เซอร์ด้วยไฟล์ตัวอย่าง: `.xlsx` หลายชีต และ `.csv` UTF-8 BOM ภาษาไทย; ตรวจที่ความกว้างมือถือ และธีมมืด

## Out of scope

บันทึกรายชื่อข้ามการเปิดเว็บ, เสียง, สุ่มหลายคน/แบ่งกลุ่ม, หลายธีม, CSV แบบ TIS-620 (Excel ภาษาไทยรุ่นใหม่ export เป็น UTF-8; ถ้าเจอปัญหาให้ใช้ .xlsx แทน)
